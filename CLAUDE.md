# GI Hub 3.0

1. **Two stacks, one Postgres.** React 19 + Ant Design v6 → FastAPI (async SQLAlchemy) → PostgreSQL 16 on `:5433` lives in `frontend/` + `backend/` and is where all work happens; the frozen Streamlit app in `legacy/` gets no new features. Bridge tools in `tools/`, archived data in `data-archive/`. [`REPO_MAP.md`](REPO_MAP.md) is the segregation contract and [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) is the system brain.
2. **Read [`.claude/RULES.md`](.claude/RULES.md) before you change anything.** It restates the locked rules an agent breaks most often — **15** (tests never open the live database), **1c** (the SME subset formula, and both engines change together), **13** (docs are part of Done), **14** (nav is a role matrix that fails closed) and **9** (the assistant's fence runs before the score). [`PROJECT_HANDOVER.md`](PROJECT_HANDOVER.md) is the full authority; when anything disagrees with it, it wins.
3. **Every gate must be green before you say "done"** — `bash bin/ci_preflight.sh` · `GI_DOTENV=0 .venv/bin/python -m backend.api.service_tests` · `npm run parity:sme --prefix frontend` · `npm run test:ui-math --prefix frontend` · `npm run test:nav --prefix frontend` · `.venv/bin/python -m tests.ai_eval.runner` · `.venv/bin/python legacy/bug_check.py` · `npm run build --prefix frontend` · `cd tests/e2e && npm test`. Full invocations with env vars are in [`.claude/RULES.md`](.claude/RULES.md) §Gates.
4. **A feature change that does not update [`MANUAL_TESTING_GUIDE.md`](MANUAL_TESTING_GUIDE.md) and [`USER_MANUAL.md`](USER_MANUAL.md) is not finished** (rule 13), and a numeric change that touches only one of the two SME engines is a bug the parity gate will catch — change both in the same commit.
